# Antirisk Hitbox

Fabric client mod for Minecraft **1.21.4**.

## Hitbox

- `H` — включить/выключить увеличение хитбоксов.
- `Numpad +` — увеличить размер на `0.1x`.
- `Numpad -` — уменьшить размер на `0.1x`.
- По умолчанию: `1.5x`.
- Диапазон: `1.0x`–`5.0x`.
- Свой хитбокс игрока не изменяется.
- Изменяются хитбоксы живых сущностей на клиенте.

Проект использует Fabric Loom, Minecraft 1.21.4, Java 21 и Yarn mappings.
